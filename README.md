# Fresh JavaFX App 🎧

A JavaFX application with a graphical interface inspired by Ed Piskor's comic book about hip-hop culture, “Hip Hop Family Tree.”

## 🚀 Features
* Custom CSS interface (`radial-gradient`, comic-style typography).
* Dynamic responses when interacting with buttons.
* JavaFX architecture using the MVC pattern.
